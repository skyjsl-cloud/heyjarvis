# 헤이 자비스 웹 테스트

`index.html` 한 파일에 호출어 모델 3개가 들어 있다. 인터넷이 연결돼 있어야 처음에 모델 실행기(onnxruntime-web)를 불러온다.

## PC에서 바로 테스트

1. `index.html`을 Chrome으로 연다 (파일을 Chrome 창에 끌어다 놓기).
2. **듣기 시작** → 마이크 허용.
3. 영어 발음으로 "Hey Jarvis" → 점수가 0.5를 넘으면 삑 → 한국어로 "클로드" 같은 명령.

## 폰에서 테스트 (깃허브 페이지)

폰 브라우저는 https 주소에서만 마이크를 쓸 수 있어서, 깃허브 페이지에 올리는 게 가장 쉽다.

1. 깃허브에서 새 저장소 만들기 (예: `hey-jarvis`).
2. **Add file → Upload files** 로 `index.html` 업로드 → Commit.
3. 저장소 **Settings → Pages** → Branch를 `main`, 폴더 `/ (root)` → Save.
4. 1~2분 뒤 `https://<아이디>.github.io/hey-jarvis/` 를 갤럭시 Chrome(아이폰은 Safari)으로 연다.

깃허브 페이지는 공개 주소라서, 모델 출처(openWakeWord, CC BY-NC-SA 4.0)가 페이지 아래에 표시돼 있다. 개인 테스트용으로만 쓴다.

## 웹 버전에서 되는 것과 안 되는 것

| | 갤럭시 Chrome | 아이폰 Safari | PC Chrome |
| --- | --- | --- | --- |
| 헤이 자비스 인식 | O | O | O |
| 한국어 명령 받아쓰기 | O | O | O |
| 앱 열기 | O (안 열리면 "열기" 버튼) | 웹 주소만 | 웹 주소만 |
| 화면 끄거나 다른 앱일 때 듣기 | X | X | 탭이 열려 있으면 O |

화면이 꺼진 상태나 다른 앱을 쓰는 중에도 부르려면 안드로이드 앱 버전을 쓴다.
명령어와 민감도는 그 브라우저에만 저장된다.
